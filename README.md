# Raupenroboter mit webbasierter Fernsteuerung
Dieses Repository enthält den vollständigen Quellcode und die CAD-Dateien eines selbst gebauten mobilen Raupenroboters. Der Roboter wird über eine eigens entwickelte Webapplikation gesteuert und ist sowohl im lokalen Netzwerk als auch über das öffentliche Internet erreichbar.

Ein Demonstrationsvideo zeigt den Roboter im Betrieb und die Bedienung der Webapplikation: https://www.youtube.com/watch?v=vNyBPZv4xP0
